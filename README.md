# Bank Customer Retention Analytics using AI

## IBM SkillsBuild Data Analytics with AI Internship 2026

**Prepared by: Jhil Patel**

## Project Overview

This project uses data analytics to understand bank customer exit patterns and translate analytical findings into business-oriented insights and actions.

The workflow is:

Raw Data → Data Cleaning → KPI Analysis → Exploratory Data Analysis → AI-Assisted Interpretation → Business Insights → Business Actions

## Problem Statement

How can data analytics and AI-assisted interpretation help a bank understand customer exit patterns and identify opportunities to improve customer retention?

## Objectives

- Clean and validate the customer dataset.
- Calculate important business KPIs.
- Explore customer exit patterns.
- Analyze demographic, financial and behavioural characteristics.
- Identify important observed differences between customers who stayed and exited.
- Use AI to assist with analytical interpretation.
- Convert findings into practical business recommendations.

## AI Component

Python is used for data cleaning, KPI calculation and exploratory analysis.

AI is used as an analytical assistant to interpret aggregated analytical results and structure them into:

Fact → Insight → Risk/Opportunity → Action

The AI output is validated against the Python-generated evidence.

The project does not use machine-learning prediction as its core methodology.
